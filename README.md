# lux's RNG

a browser-based RNG game. roll cubes, earn credits, buy upgrades, unlock achievements.

## play

- **github pages:** https://iluxz.github.io/luxs-rng/
- **githack (school fallback):** https://raw.githack.com/iluxz/luxs-rng/main/index.html

## features

- 33 rarities from Dust to ???
- auto roll, x10/x100 multipliers (x100 is 50k credits)
- shop with luck bracelets, gloves, talismans, credits bracelet
- 40+ achievements that give permanent luck boosts
- manual roll cooldown (500ms)
- localStorage save/load
- update log + stats (best roll, playtime)
- screen effects, particles, audio

## controls

- **click canvas** or **space** to roll
- **roll button** for manual roll
- **auto button** toggles auto roll (forced x1)
- **shop/achievements/update log** buttons in header

## tech

single-file html (css + js inlined). no dependencies. no build step.
